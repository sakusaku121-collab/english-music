# ヘッドホンスタンド(割れにくさ優先)

MakerWorld のスタンドが、はめ込み(あり継ぎ)の口の横で裂けて手を切ったので、同じ割れ方をしないように一から設計したもの。

- `stand.scad` … 設計データ(寸法は先頭の数値で変えられる)
- `stl/stand_lower.stl` と `stl/stand_upper.stl` … 上下2つ(高さ 225mm、幅 70mm)。重ねて接着する。エレコム HS-HP06SUBK(高さ約200mm)用

## 形と、割れにくくした所
1. 横から見た形を台に寝かせて刷る。曲げの力が積層の線に沿ってかかり、層の間を引きはがさない。サポート不要。
2. くさびになる継ぎ手を使わない。上下は厚みを半分ずつ重ねる「相欠き」で、面どうしを接着する。位置合わせのダボは横向きに付く。
3. 内側の角はすべて丸め、幅の面の縁は面取りする。
4. 腕の板そのものをしならせた形。真ん中が 3mm くぼんでバンドが収まり、先が 7mm なだらかに反り上がって前に滑り落ちない。
5. 土台は元のモデルのように、柱から大きな丸み(半径 45mm)で曲がって続く1枚の板。上から見た前の角は丸く、後ろの下の角も丸めてある。左右に倒れにくいよう幅を 70mm にした。台に付く側の前の角だけは、サポートなしで刷れるよう 45° で落としてから丸めている(気になればやすりで丸める)。

## 刷り方
- STL は置いたままの向き(横から見た形が台の上)で刷る。サポートなし。
- 素材は PETG(Bambu PETG Basic)。PLA より裂けにくく、割れても口が鋭くなりにくい。
- 壁面層数 5、インフィル 25% ジャイロイド。
- 上下を重ねる面をエポキシ接着剤で貼り、固まるまで洗濯ばさみ等で押さえる。
