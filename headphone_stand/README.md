# ヘッドホンスタンド(割れにくさ優先)

MakerWorld のスタンドが、はめ込み(あり継ぎ)の口の横で裂けて手を切ったので、同じ割れ方をしないように一から設計したもの。

- `stand.scad` … 設計データ(寸法は先頭の数値で変えられる)
- `stl/stand_lower.stl` と `stl/stand_upper.stl` … 本体の上下2つ(高さ 225mm、幅 70mm)。重ねて接着する。エレコム HS-HP06SUBK(高さ約200mm)用
- `stl/stand_plate.stl` … 扇形の土台板(後ろ 84mm → 前 130mm に広がる)。くぼみに本体の土台をはめて接着すると、上の面が段差なしでそろう

## 形と、割れにくくした所
1. 横から見た形を台に寝かせて刷る。曲げの力が積層の線に沿ってかかり、層の間を引きはがさない。サポート不要。
2. くさびになる継ぎ手を使わない。上下は厚みを半分ずつ重ねる「相欠き」で、面どうしを接着する。位置合わせのダボは横向きに付く。
3. 内側の角はすべて丸め、幅の面の縁は面取りする。
4. 腕の板そのものをしならせた形。真ん中が 3mm くぼんでバンドが収まり、先が 7mm なだらかに反り上がって前に滑り落ちない。
5. 元のモデル(Deltaprints)の写真を見て、同じ厚み(8mm)の板1枚を曲げたような形にした。柱から土台・腕への曲がりは、内側と外側が同じ中心の円。土台は柱と同じ幅・同じ厚みの薄い板で、前の角は丸い。下の曲がりの内側の半径は 16mm(外側 24mm)。これより大きいと机に付く所が前へ下がり、スタンドだけのときに後ろへ倒れる(重心は柱の後ろの面から 35mm、机に付き始めるのは 24mm)。台に付く側の前の角だけは、サポートなしで刷れるよう 45° で落としてから丸めている。

6. 土台は元のモデルのように柱より広い扇形(柱の付け根から前へ、ゆるい曲線で左右に広がる)。本体は横から見た形を寝かせて刷るので幅 70mm より広くできず、土台板を別に寝かせて刷ってはめ込む。左右に倒れにくくなる。

## 刷り方
- STL は置いたままの向き(横から見た形が台の上)で刷る。サポートなし。
- 素材は PETG(Bambu PETG Basic)。PLA より裂けにくく、割れても口が鋭くなりにくい。
- 壁面層数 5、インフィル 25% ジャイロイド。
- 上下を重ねる面と、土台板のくぼみをエポキシ接着剤で貼り、固まるまで洗濯ばさみ等で押さえる。
- 土台板は上から見た形を台に寝かせた向き(くぼみが上)で刷る。
