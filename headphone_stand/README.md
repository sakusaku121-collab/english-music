# ヘッドホンスタンド(割れにくさ優先)

MakerWorld のスタンド(Deltaprints「スイング」)が、柱の下のはめ込み(あり継ぎ)の口の横で裂けて手を切ったので、同じ割れ方をしないように一から設計したもの。大きさは元のモデル(244×122×120mm)に合わせた。組んだ大きさは高さ約 242mm、奥行き約 123mm、幅約 115mm。

- `stand.scad` … 設計データ(寸法は先頭の数値で変えられる)
- `stl/stand_print_set.stl` … **3つの部品を A1 mini の台に並べたもの。これ1つで、1回で刷れる**
- `stl/stand_lower.stl` … 柱(下の曲がりと、土台板に差し込む舌まで継ぎ目なしの1本)
- `stl/stand_upper.stl` … 腕(上の曲がりから先)
- `stl/stand_plate.stl` … 扇形の土台板

## 形
- 同じ厚み(8mm)の板1枚を、直線と円弧をなめらかにつないだ1本の線に沿って曲げた形。土台から大きく曲がって立ち上がり、柱は少し前へ傾きながらゆるく弧を描き、上で前へ回り込んで腕になる。
- 腕は先へ向かって 8mm から 6mm に細くなり、根元のすぐ先が 3mm ほどくぼんでバンドが収まり、先がふわっと反り上がって前に滑り落ちない。
- 土台は元のモデルのように柱より広い扇形(後ろ 84mm → 前 120mm)。

## 継ぎ目の場所
- 柱の背中には継ぎ目を作らない(元のモデルはそこで割れた)。柱は土台板に差し込む舌から上の曲がりの手前まで1本。
- 腕との継ぎ目は上の曲がりのすぐ下(高さ 172〜204mm)。ヘッドホンの重さで曲げる力はここが一番小さい。
- 土台板とは、柱の下の舌を差し込んでつなぐ。

## 割れにくくした所
1. 部品はどれも横から見た形(土台板は上から見た形)を台に寝かせて刷る。曲げの力が積層の線に沿ってかかり、層の間を引きはがさない。サポート不要。
2. 接着剤もネジも使わない。継ぎ目の「あり」と溝は台の面の中の形なので、溝のまわりを樹脂の線が囲み、層の境目で裂けない。
3. 尖った角を作らない。

## 組み立て
1. 腕を、柱の上の継ぎ目に横(幅の方向)から滑り込ませる。腕の、刷ったとき台に付いていた側に溝の行き止まりがあるので、そちらが奥になるように入れる。奥ほど少しきつくなり、最後まで入れると締まる。
2. 柱の下の舌を、土台板のくぼみに後ろから差し込む。くぼみの縁が舌の面取りにかぶさり、奥ほど少しきつくなる。
- きつすぎて入らないときは無理に押さず、こすれる所を紙やすりで少し削る(押し込むと割れの元になる)。

## 倒れにくさ(計算)
- 重心は柱の後ろの面から 45mm、高さ 96mm(スタンドだけ、中身を詰めた場合)。
- 傾けて倒れるまでの角度: 後ろ約 25°、横約 27°、前約 39°。ヘッドホンを掛けると重心が前に寄り、後ろにはさらに倒れにくくなる。

## 刷り方
- `stand_print_set.stl` をそのまま読み込んで刷る(並べ替えない)。サポートなし。
- 素材は PETG(Bambu PETG Basic)。PLA より裂けにくく、割れても口が鋭くなりにくい。
- 壁面層数 5、インフィル 25% ジャイロイド。
