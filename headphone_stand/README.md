# ヘッドホンスタンド(割れにくさ優先)

MakerWorld のスタンド(Deltaprints「スイング」)が、はめ込み(あり継ぎ)の口の横で裂けて手を切ったので、同じ割れ方をしないように一から設計したもの。大きさは元のモデル(244×122×120mm)に合わせた。組んだ大きさは高さ約 242mm、奥行き約 123mm、幅約 115mm。

- `stand.scad` … 設計データ(寸法は先頭の数値で変えられる)
- `stl/stand_lower.stl` … 本体の下(土台と柱の下)
- `stl/stand_upper.stl` … 本体の上(柱の上と腕)
- `stl/stand_plate.stl` … 扇形の土台板

## 形
- 同じ厚み(8mm)の板1枚を、直線と円弧をなめらかにつないだ1本の線に沿って曲げた形。土台から大きく曲がって立ち上がり、柱は少し前へ傾きながらゆるく弧を描き、上で前へ回り込んで腕になる。
- 腕は先へ向かって 8mm から 6mm に細くなり、根元のすぐ先が 3mm ほどくぼんでバンドが収まり、先がふわっと反り上がって前に滑り落ちない。
- 土台は元のモデルのように柱より広い扇形(後ろ 84mm → 前 120mm)。本体は横から見た形を寝かせて刷るので幅 70mm より広くできず、土台板を別に刷って差し込む。

## 割れにくくした所
1. 本体は横から見た形を台に寝かせて刷る。曲げの力が積層の線に沿ってかかり、層の間を引きはがさない。サポート不要。
2. 接着剤もネジも使わない。継ぎ目の「あり」と溝は横から見た面の中の形なので、溝のまわりを樹脂の線が囲み、層の境目で裂けない。
3. 尖った角を作らない。

## 組み立て
1. 上の部品を、下の部品の継ぎ目に横(幅の方向)から滑り込ませる。上の部品の、刷ったとき台に付いていた側に溝の行き止まりがあるので、そちらが奥になるように入れる。奥ほど少しきつくなり、最後まで入れると締まる。
2. 本体の土台を、土台板のくぼみに後ろから差し込む。くぼみの縁が土台の面取りにかぶさり、奥ほど少しきつくなる。
- きつすぎて入らないときは無理に押さず、こすれる所を紙やすりで少し削る(押し込むと割れの元になる)。

## 倒れにくさ(計算)
- 重心は柱の後ろの面から 45mm、高さ 97mm(スタンドだけ、中身を詰めた場合)。
- 傾けて倒れるまでの角度: 後ろ約 25°、横約 27°、前約 39°。ヘッドホンを掛けると重心が前に寄り、後ろにはさらに倒れにくくなる。

## 刷り方
- STL は置いたままの向きで刷る。本体2つは横から見た形が台の上、土台板はくぼみが上。サポートなし。
- 素材は PETG(Bambu PETG Basic)。PLA より裂けにくく、割れても口が鋭くなりにくい。
- 壁面層数 5、インフィル 25% ジャイロイド。
