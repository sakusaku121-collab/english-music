# ヘッドホンスタンド(割れにくさ優先)

MakerWorld のスタンドが、はめ込み(あり継ぎ)の口の横で裂けて手を切ったので、同じ割れ方をしないように一から設計したもの。

- `stand.scad` … 設計データ(寸法は先頭の数値で変えられる)
- `stl/stand_one_175.stl` … 継ぎ目なしの一体(高さ 175mm。A1 mini に入る上限)
- `stl/stand_lower.stl` と `stl/stand_upper.stl` … 2つに分けた版(高さ 225mm)。重ねて接着する。エレコム HS-HP06SUBK(高さ約200mm)用
- `stl/stand_foot.stl` … 幅の広い足の板(110mm)。本体の幅 50mm だけだと左右に倒れやすいので、土台をくぼみにはめて接着する

## 割れにくくした所
1. 横から見た形を台に寝かせて刷る。曲げの力が積層の線に沿ってかかり、層の間を引きはがさない。サポート不要。
2. くさびになる継ぎ手を使わない。2つに分ける版は厚みを半分ずつ重ねる「相欠き」で、面どうしを接着する。位置合わせのダボは横向きに付く。
3. 内側の角はすべて丸め、幅の面の縁は面取りする。
4. 腕の板そのものをしならせた形にした。真ん中が 7mm くぼんでバンドが収まり、先が 10mm 反り上がって前に滑り落ちない。

## 刷り方
- STL は置いたままの向き(横から見た形が台の上)で刷る。サポートなし。
- 素材は PETG(Bambu PETG Basic)。PLA より裂けにくく、割れても口が鋭くなりにくい。
- 壁面層数 5、インフィル 25% ジャイロイド。
- 2つに分ける版は、重ねる面をエポキシ接着剤で貼り、固まるまで洗濯ばさみ等で押さえる。足の板のくぼみにも土台を接着する。
- 一体版(175mm)は、ヘッドセットのバンドを一番短くしても足りない可能性が高い。
