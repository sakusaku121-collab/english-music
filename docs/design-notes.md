# 設計ノート — なぜこの仕様なのか

## 発端

市販の左手デバイス(Mouserpad v2、¥7,590)を検討したが、実際のプレイで致命的な問題があった:

1. **レレレ中のダッシュ暴発**
   Apex のホライゾンで、グラビティリフトで浮きながらバッテリーを巻き、
   弾避けに左右移動(レレレ)を混ぜると、スティックが前方向を含んだ瞬間に
   オートダッシュ(Shift)が乗って回復がキャンセルされる。
2. **前進しながらの回復も不可**
   回復しつつ前に進みたいとき、スティックを倒しすぎるとオートダッシュが
   発動して同じくキャンセル。つまり「回復中はスティックを慎重に倒す」
   ことをプレイヤー側が強いられる。

市販品はこの挙動を変更できない。→ 自作すれば設計レベルで直せる。

## 主要な設計判断

### D1. ダッシュは独立した物理ボタン(デフォルト)

- スティック入力とスプリントを完全に分離する。
  スティックをどれだけ・どの方向に倒しても Shift は乗らない。
- 誤爆源を「賢い制御で抑える」のではなく「構造的に消す」。
  デバッグが楽で、挙動が予測可能。

### D2. オートダッシュはオプションとして残す(比較・他ゲー用)

- プロファイル `auto-dash` で有効化できる。
- ただし市販品との差別化として:
  - **発動閾値を高めに設定可能**(threshold 0.92〜)
  - **コンテキスト抑制**: 回復キー(4)を押した直後 N 秒間は
    オートダッシュを無効化。バッテ5秒/医療キット8秒に合わせて調整。

### D3. プロファイルは本体フラッシュに保存

- `microcontroller.nvm` に選択中インデックスを保存。
- どの PC に挿しても同じ挙動。ドライバ・常駐ソフト不要
  (= 販売時のサポートコストが低い)。

### D4. 有線 USB 固定

- 無線化すると技適(電波法)が必要で個人販売には非現実的。
- 有線 USB バスパワーなら PSE(電気用品安全法)も対象外。

### D5. ファームウェアは完全自作(CircuitPython)

- GPL 系の既製ファームウェアを流用するとソース公開義務が絡む。
  販売を見据えて MIT でクリーンに保つ。
- 挙動の芯(8方向判定、ヒステリシス、抑制ロジック)は 200 行程度で書ける。

### D6. 筐体はオリジナル形状

- Mouserpad v2 の形状をそのまま複製して販売すると
  不正競争防止法(形態模倣、発売から3年)に触れるおそれ。
- どのみち自分の手に合わせてグリップを再設計するので、
  パラメトリックモデル(case.scad)で角度・配置を数値管理する。

## 自分で使っての感想(Mouserpad v2、2026-11-22)

- 痛くなるところ、疲れるところは特になし
- 一番気に入っているのは、**親指の位置を中心にボタンが扇形に並んでいる**こと

→ 握りの形は大きく変えずに、全体の大きさ(90×125×120mm)と扇形配置を土台にする。
  変えるのは、レビューで出た機能面(ダッシュ分離、ESC、割当変更、床ボタン、USB-C)。
  形はまねせず、寸法の比率だけを参考にする(不正競争防止法の形態模倣を避ける)。

## Mouserpad v2 の写真から測った寸法(2026-11-22、試作2号に反映)

向き: 天面の 1・2 が手前、土台は手前と左(手のひら側)に張り出す。人差し指・中指のボタンはモニター側の前面。

- 外寸 幅90×奥行125×高さ120(商品ページ)。正面写真で、天面の幅 約75、胴体の幅 約48、土台は胴体の左へ 約22 張り出す
- 横から: 胴体の後ろ側は手前へ傾いて下がる(約19°)。前面は垂直で、ボタンは高さ 約40〜90
- 前面ボタンの下(高さ 約17〜35)に、薬指・小指の先が入るくぼみ
- 天面は平らな板(約80×75)で、前が高くなる向きに 約9〜11° 傾く
- 天面のボタン: スティックの左と手前に2重の扇形。内側(Tab F Q E X)は半径 約22、外側(3 4 1 2)は 約37

試作2号での変更:
- 天面を盛り上がった形から平らな板に。ボタンを Mouserpad と同じ2重の扇形に
- 胴体を細い柱から、前後に長く左右に薄い形(手のひらを左面に当てる)に
- ESC はボタンのない右前に置き、0.3秒の長押しで送る(親指がかすっても誤爆しない)
- 床ボタンは前面の下のくぼみの床へ。薬指・小指で押し下げる位置(届くかは試作で確認)

試作3号(見た目の作り直し):
- 2号は輪切りを箱型でつないでいて、箱に板を載せたような形だった
- 断面を角の丸い四角(超楕円)にし、下から上へ曲線でつないだ1枚の曲面に変更。
  柱の中ほどにくびれ、天面へ向かって広がり、土台へは裾を広げてつなぐ
- 天面は胴体の上端をそのまま傾けて平らにし、縁を半径5mmで丸める

試作4号(握る部分と天面の作り直し):
- 3号は握る部分が奥行き 約95・幅 約48 で太すぎた(Mouserpad の横写真で奥行きを読み違えた)。
  手の小さい人でも握れるよう、握る部分を奥行き 約63・幅 約41 の首にし、天面へ向かって広げる
- 扇形の起点を決め直した。スティックを中心に、親指の付け根の向き(左やや手前、115°)を真ん中にして ±90° にだけボタンを置く。
  内側の列は5個を45°おき、外側の列は扇の両端に2個ずつ(付け根の真上は届かないので空ける)。
  ESC は扇の外(指を伸ばす右前)に置く
- 天面の外形も四角をやめ、この扇に沿った形にした

## 販売までのロードマップ

1. **自分用1号機**: PLA試作でグリップ形状を確定 → PETG で常用機
2. **公開**: SNS で反応を見る(写真+ダッシュ分離のデモ動画)
3. **販売版設計**: QC しやすい分割、キーキャップ色替えでカラバリ、
   Raspberry Pi 財団の VID/PID 割当を申請
4. **販路**: BOOTH から開始 → 反応次第で Makuake 等のクラファン
